# TaskVilla 0.46.0 — Wooden icons and consistent task controls

Author: Aniruddha DuttaChowdhury · ADChowdhury

Changes since the previous published release, 0.40.0:

- The Home Settings button uses the approved walnut, cream and muted-metal gearwheel, fitted to the existing button.
- Latest task on top uses a Reminders-style themed switch and approved wooden ordering artwork in Create list and List options.
- Changing that switch reverses the list's existing task order on Save. Switching off reverses it back; unchanged saves do not reverse again. New tasks go first while enabled. Discard and save failures preserve saved order.
- Icon and theme selectors share a row in List options, each with a down arrow.
- Create task and task edit use equal-width Cancel on the left and Save on the right, retaining bevel styles, validation and unsaved-change prompts.

Package app.adc.taskvilla; versionCode 46; original signing identity and SQLite schema 4 preserved. Existing lists, tasks, attachments and Activity Tracker remain intact.

This publication reuses the already-built APK. The build signature and packaged assets were verified when it was prepared. Focused browser ordering and selector checks were performed for 0.42.0; subsequent visual changes did not receive additional runtime tests. No rebuild or phone installation was performed for this publication.
