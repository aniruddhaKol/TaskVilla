# TaskVilla 0.36.0 — Activity list layout

Author: Aniruddha DuttaChowdhury · ADChowdhury

Opening Activity Tracker from Home always selects All and clears the previous search. Returning from activity details preserves the current tab and filter. The default tracker view is All.

Activity details now has a compact, right-aligned Add entry button instead of a full-width action. Activity list cards follow the supplied reference: activity icon at left, title and Last/Next dates beside it, and latest amount right-aligned. Unscheduled entries say No schedule. The previous separate due badge is removed. Large amounts use smaller single-line text. Existing themes, alternating card surfaces and tap feedback remain.

Package app.adc.taskvilla; versionCode 36; original signing identity, SQLite schema 4 and backup format 2 unchanged. Local release only; no Git publication or phone installation.
