# TaskVilla 0.27.0

Author: Aniruddha DuttaChowdhury · ADChowdhury

- Block duplicate attachments within a task using actual byte size and CRC32, including renamed files and duplicates in one selection.
- Keep the same file attachable to different tasks. Equal-size files with different CRC values are accepted.
- Reject a failed selection atomically and remove its newly created private copies. Existing attachments remain intact.
- Compute CRC for older private attachments on demand.
- Verified existing cleanup after successful SQLite persistence: deleting a task or list removes only unreferenced private attachment copies; other tasks, other lists and active drafts remain intact. Device originals are retained.

Package app.adc.taskvilla; versionCode 27; same review signing certificate, SQLite schema 3 and metadata-only backup format 2. No backend integration or list-sharing tests. Review APK updates earlier TaskVilla review builds.
