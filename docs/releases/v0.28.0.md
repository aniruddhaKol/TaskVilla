# TaskVilla 0.28.0

Author: Aniruddha DuttaChowdhury · ADChowdhury

Today, Planned and Favourites now appear as three compact home-screen boxes in a single row, following SMSAnalyzer's paper surfaces, accent strips, centred labels and icon/count layout. Boxes have 5px corners, 2px gaps, visible focus and tap feedback. Counts and destinations share the same incomplete-task filter. Favourites includes starred tasks with or without a due date. Completed tasks are excluded.

The duplicate attachment notice now reads “Same file already attached”. Matching size and CRC32 are still checked within each task only; the same file is allowed in different tasks.

Package app.adc.taskvilla; versionCode 28; existing review signature, SQLite schema 3 and backup format 2 retained. Fresh installs remain empty. Screenshot fixtures are synthetic and are not included as app data. No backend or list-sharing changes. Install the APK on Android 8+ to update a previous review build.
