# TaskVilla v0.24.0 — Field focus and keyboard layout

Author: Aniruddha DuttaChowdhury · ADChowdhury

## Changes since v0.22.0

- Enlarged the home Settings gear from 20 to 32 pixels inside the existing 36-pixel bevelled button (v0.23.0).
- Corrected the task-name field sizing and padding so its focus rectangle stays inside the row.
- Added complete inset focus outlines for editable fields and date controls.
- Added shared visible-viewport handling to keep focused fields above the keyboard and Save bar, including nested picker/dialog fields, and restore previous scroll positions after dismissal.
- Extended the Android keyboard helper from only the new-task title to editable text, notes, email, number and search fields throughout the app.

## Validation

- Browser checks passed at 320/390/412 px for title focus containment. Simulated keyboard viewport checks passed for notes, list name and emoji popup input, field switching, create-task autofocus, retained edits and scroll restoration, with no JavaScript errors.
- APK built, installed and signature-verified with the existing signing certificate (v2/v3). Packaged UI files match the delivered source.
- Real Android keyboard validation is incomplete: emulator network/system services crashed and System UI subsequently stopped responding; the IME did not open. Browser viewport checks are not a substitute for device keyboard validation.

## Known limitations

- File attachment is not working as expected. This release does not implement working attachment storage or sharing; the current prototype records filenames only.
- Notifications, email OTP authentication, server sync and live list sharing are not connected. SQLite remains local; fresh installs start empty.
- This is a debuggable Android review build, not a production release.

## Deferred to the next release

The owner requested the following attachment work; it is recorded only and is NOT implemented in v0.24.0:

- Repair attachment handling and support multiple files.
- Limit each file to 10 MB, with a proposed maximum of 10 files per task.
- Display a clear notice explaining attachment limits and any storage/sharing constraints.
- Allow attached files to be shared through installed apps.

## Install / upgrade

Version 0.24.0, versionCode 24, package app.adc.taskvilla. The original signing identity and SQLite schema 3 are preserved. Install the APK over a previous TaskVilla review build to retain local data. Android 8.0/API 26 or newer is required. Older APKs remain preserved in the repository.
