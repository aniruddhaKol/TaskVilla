# TaskVilla v0.25.0 — Draft protection and local attachments

- Back from changed task/list editors opens Discard | Save. Close stays on the form; Save validates and saves before returning.
- Multiple attachments: maximum 10 files per task, at most 10 MB (10,000,000 bytes) each. Files are copied into private Android storage and can be shared individually or together through installed apps.
- Added a neutral attachment-limit disclaimer with the established yellow warning icon. Existing filename-only entries are preserved and marked for reattachment.
- JSON/XML backup format 2 exports attachment metadata only, not file bytes.
- Original package/signing identity and SQLite schema are retained; install over earlier TaskVilla review builds to preserve local data.

Validation: browser draft/limit/keyboard-regression checks and native file/provider/share-intent instrumentation passed. Interactive picker/recipient handoff and complete native IME testing remain unverified. This remains a debuggable local review build with no backend/list-sharing service.
