# TaskVilla 0.30.0

Author: Aniruddha DuttaChowdhury · ADChowdhury

New task and new list now use the same unsaved-change guard as task editing and list options. Changed forms show Discard (left) and Save (right) when leaving. Discard leaves without committing; Save validates and persists before leaving; the top cross or Android Back closes only the prompt and keeps the draft. Unchanged forms leave directly. Detection covers text, dates, stars, list appearance, people and attachments as applicable. New-list creation now persists transactionally through the draft editor; failed persistence keeps the draft and removes the attempted new record from the in-memory saved model. Normal Save still opens the newly created list; Save from the Back prompt follows the requested return destination.

Package app.adc.taskvilla; versionCode 30. Existing signing identity, SQLite schema 3, backup format 2, BookShelves theme, buttons and data model are preserved. Fresh installs remain empty. No Git push or release publication; APK built for local review.
