# TaskVilla 0.32.0 — Personal Activity Tracker

Author: Aniruddha DuttaChowdhury · ADChowdhury

- A “Latest task on top” checkbox is available when creating or editing a list. New tasks are inserted at the top when enabled and at the bottom when disabled. Existing task order is retained when toggling; manual drag sorting remains available. The setting participates in Save/Discard.
- Task notes are a newest-first comment thread. Add, edit and confirmed delete work within the task draft; Save commits them and Discard restores the original thread. Pending composer text is included on Save. Existing legacy notes become a preserved first comment without an invented timestamp; old long notes are retained. New/edited comments are limited to 280 characters and task names to 100, with validation and red focus.
- Extensive list copy now includes only Task Name, Due Date and Tags, with headers, in HTML table/TSV formats. Plain-text copying still copies incomplete task names. No notes, subtasks, filenames or other fields are copied.
- Added a personal, device-only Activity Tracker button using the supplied icon. Upcoming, All and History views include search, last/next dates and amounts. Add/edit activities and dated entries, confirmed deletion, interval calculation (0–365 days; 0 disables scheduling), detailed history, filtered history and spending trends are implemented. Trends show monthly spending and per-entry total/average/highest/lowest. Date calculations use actual calendar days rather than a fixed month length.
- Title autocomplete uses all 110 supplied activity/icon/category suggestions plus saved personal types, prioritising title matches. Unlisted names can be added and become local suggestions. Suggestions are not pre-created activity records: fresh installs start empty.
- Tracker forms use required date/title, amount/interval/length validation and the same unsaved-change guard. Failed saves retain drafts. There are no activity invitations, members, share controls or network synchronization.
- Wood, Stone, Brick and BookShelves remain supported. Existing buttons, colours, 5px corners and list banners are retained; new edit/delete controls follow the learned grey/red bevels. Reused SMSAnalyzer's shared fast-tap feedback module. Native date picking supports tracker dates as well as task dates.

Package app.adc.taskvilla; versionCode 32. The original review signing certificate is retained. SQLite migrates non-destructively from schema 3 to 4, adding list preference/comment columns; personal tracker data is stored separately in SQLite preferences. Backup format remains 2, with dataSchemaVersion 4 and tracker/comment data included. Attachment bytes are still excluded from exports. No restore UI is added.

This is a local review release. Nothing was committed, pushed, tagged or published to GitHub, and no phone installation was attempted.
