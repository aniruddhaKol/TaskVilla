# TaskVilla v0.26.0 — Attachment controls and date picker

- Attach files is the sole top-level file action; individual files can still be shared.
- Files (n/10) counter, newest-first order and alternating row backgrounds.
- Trash-can removal buttons with confirmation; Cancel keeps files, Remove stages removal and Discard restores originals.
- Short yellow-icon disclaimer: Max 10 files of 10 MB each.
- Task-list paperclip immediately before the star when attachments exist.
- Explicit Android date picker restored for create/edit tasks; current date selection and dd-MMM-yyyy display preserved.

Browser integration, migration/restart simulation and actual native date-dialog checks passed. Original package, signing certificate, SQLite data and earlier versions preserved. Local review build; no server/list-sharing services. Interactive attachment recipient handoff and full IME checks remain outside verified coverage.
