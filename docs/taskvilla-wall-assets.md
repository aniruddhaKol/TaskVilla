# Wall theme assets

Author: Aniruddha DuttaChowdhury · ADChowdhury

The Stone wall and Brick wall textures in v0.11 use the two reference PNGs supplied by the user on 2026-10-10. Files are copied unchanged to both preview and Android assets, preserving their original pixels. CSS repeats the textures at their original aspect ratios with a slight dark overlay for readability. Original SVG wall assets and earlier releases are preserved. No third-party source or licence was asserted for the supplied images.
